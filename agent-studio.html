agents/agent-test.yaml is now a complete definition:

  • Kept as-is: slug, name: AGENT TEST, and the TEST intent — the description just says what it tests.
  • Instruction: a fixed four-line echo response (OK / received: / length: / turn:) with explicit rules against tidying up the echoed input, since a cleaned-up echo would mask a transport bug.
  • Tools/guardrails/knowledge: empty — a probe should have nothing between it and the model.
  • Model: unchanged (xai/grok-4.3, reasoningEffort: none, fallback xai/grok-4.6) — echoing needs no deliberation.
  • Limits: tightened from the scaffold defaults to maxTurns: 4, maxTokensPerRun: 20000, autonomyLimit: 2. A test agent that can burn 120k tokens over 16 turns is a way to lose money to a loop.
